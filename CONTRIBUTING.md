# Contributing

Pull requests are not accepted on this repository.

Nothing here is written by hand. Every file is regenerated and replaced wholesale on each run of an
in-house generator, so a change committed here would be overwritten by the next run rather than
reviewed. Pull requests are closed for that reason, not because the change itself is unwelcome.
Issues are not enabled either.

Corrections are still wanted, by mail. If something is wrong — an endpoint that does not match the
API, a field described the wrong way round, a description that contradicts the reference — write to
[developer@cybozu.com](mailto:developer@cybozu.com). Include the operation or schema name; a link
to the file at a commit is ideal. The fix goes into the generator and reaches this repository on
its next run.

For questions about using the API itself, see [Feedback](README.md#feedback) in the README.
